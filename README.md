Entry for the make.fun bounty **The Excuse That Almost Works**: one line (≤20 words) a gamer texts the boss to skip work during GTA 6 launch week.

The excuse is deliberately boring and specific — a gas engineer visit with an all-day 8-to-6 window that someone has to be home for. No wild story, no dead relative, no flat tyre, no sudden fever: just the kind of appointment a tired manager has heard a hundred times and can neither check nor argue with. The joke is the ten-hour window itself.

## Run

```bash
python3 main.py
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
